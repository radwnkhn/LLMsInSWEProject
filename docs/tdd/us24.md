## What changed

- **Validation (`backend/app/faults.py`).** `threshold` joined `FAULT_EDITABLE_FIELDS`. `threshold_range()`
  gives 0 to 180 for angles, -1 to 1 for hip depth (signed, in thigh lengths) and 0 to 2 for other ratios.
  `edit_fault()` and `new_fault()` share one check: a real, finite number in that range, saved as a float.
- **Repository.** `update_fault(..., changed_by=...)` logs a `ThresholdChange` (fault, old and new value,
  who, when) only when the threshold actually changes. In Postgres the row is locked and the update and its
  log entry are saved in one transaction. `list_threshold_changes()` returns the log newest first, with the
  admin's email.
- **Migration `20261115000000_us24_threshold_log.sql`.** `public.fault_threshold_changes` references the
  fault, and the admin `on delete set null`, so the log outlives a deleted account. RLS is enabled with an
  admin-read policy.
- **API.** `PATCH /admin/faults/{lift}/{id}` also accepts `threshold` and records the signed-in admin.
  Every fault in `GET /admin/faults` carries `threshold_min` and `threshold_max`.
  `GET /admin/faults/threshold-changes` returns the log with times in UTC. All of these use `admin_user`.
- **Frontend.** The fault list's Edit form has a Threshold field showing the allowed range. It's checked
  before saving, and sent only when it changed. A "Threshold changes" section lists each change
  ("10° → 12°") with the admin's email and time, and reloads after a saved threshold.

## Assumptions

- **Ranges are guard rails, not tuning advice.** They stop typos (a knee cave of 500°, a negative bar
  drift), not values a coach could reasonably want.
- **"Only new analyses."** Each analysis already takes a snapshot of the fault list when it starts (US-25),
  so a change made while one runs applies from the next. Saved results are never recomputed. Comparisons
  (US-20) judge both uploads against today's thresholds, so both are measured by the same rule.
- **Unchanged values aren't logged.** Saving the current value again, or editing only a name, adds no entry.
- **Who** is the admin's email at the time it's shown. If the account is deleted, the entry stays and shows
  "Deleted account".
